# PSS 联合判别读出：用 LDA 替掉原型余弦读出

> 日期：2026-11-28
> 范围：把生产公共空间的读出从“分模态原型余弦”换成“拼接特征的联合判别 LDA”，给出是否/何时替换的实测依据，并汇总本轮“多专家互补性”结论（§7）
> 关联：`pss/prototypes/joint_readout.py`、`pss/inference.py`、`pss/eval/scripts/run_joint_readout_eval.py`
> 上游结论：`PSS-读出与推理优化总报告.md` §4.4、`PSS-信息论定位.md` §5.4–5.6
> 本轮结论：§7（互补性是必要条件，不是充分条件）

---

## 0. 一句话

**联合判别读出在“多类、难任务”上显著更强（384 类：0.833 → 0.927，+9.4 点，95% CI [6.0, 13.0]），但在当前 6 类生产任务上并不更好（闭集 0.990 → 0.958；开集 AUROC 0.969 → 0.897）。所以生产接入做成 `auto`：按 val 选择，默认保留原型头，`readout="joint"` 显式启用联合头。盲目整体替换会掉开集。**

---

## 1. 实现

`JointReadout`（`pss/prototypes/joint_readout.py`）：

- 对每个非空模态掩码（vision / tactile / geometry 的 7 个子集）各训练一个 pooled-covariance LDA；
- 查询时按可用模态选对应掩码模型，因此单模态/缺模态仍可用；
- 特征在训练集上按模态标准化后拼接；
- 热更新：`add_class` / `update_class` 只移动类均值，池化精度矩阵冻结，更新 O(d)，其他类不受影响；
- 开放集：用原始 max score + val 校准阈值，不走 per-query 归一化；
- 原型 bank 保留，用于 per-modality top / conflict 诊断。

`PublicSemanticSpace`：

- `build_bank()` 同时拟合并保存 `joint_readout.npz`；
- `recognize(..., readout="auto")`：按 val 上 prototype vs joint 的准确率选择；
- `readout="prototype"` / `"joint"` 可显式覆盖；
- 返回新增 `readout` 字段。

## 2. 生产 6 类任务（`data/expert_v1`，96 test）

| 读出 | 闭集 top-1 | 开集 AUROC | 95% seen accept 下 unseen reject |
|---|---:|---:|---:|
| 原型余弦 | **0.990** | **0.969** | 0.990 |
| 联合 LDA | 0.958 | 0.897 | 0.958 |
| Δ（joint − proto） | −0.031，CI [−0.073, 0.000] | −0.072，CI [−0.125, −0.025] | — |

- 闭集差异 3 个样本，CI 跨 0，不显著；**开集差异显著为负**。
- 热更新：add class 约 0.31 ms/类，update 约 0.20 ms/次；加类后 seen 测试预测变化 0.0（零遗忘）。
- val 上 prototype 与 joint 都是 1.000，`auto` 选择 prototype；这是安全的默认。

## 3. 384 类投影任务（`category_pretrain_instance8`，384 test）

| 读出 | test top-1 |
|---|---:|
| 原型余弦（g 报告的 `A_current`） | 0.833 |
| 联合 LDA（128-d 投影） | **0.927** |
| Δ | **+0.094**，CI [0.060, 0.130] |

同一批 128-d 投影特征，联合读出把原型读出的 9.4 点读出税几乎全部收回。这是“换成联合判别读出”真正成立的场景。

## 4. 判读与部署建议

1. **不是无条件替换**：当前生产只有 6 类，原型已经 0.990/0.969；联合头闭集不显著、开集显著更差。
2. **多类/难任务用联合头**：384 类上 +9.4 点，CI 排除 0；这是读出的主收益。
3. **默认 `auto`**：按 val 选择；val 饱和时偏保守选 prototype。
4. **若要强制联合头**：至少同时保留原型头的开集/unknown 判断，或把联合头限定在“原型已接受”的闭集精排（双头），不要让它单独做拒识。
5. **下一步**：真实数据上重跑；调 LDA shrinkage（生产 6 类上 0.5–0.95 可把开集 AUROC 从 0.897 抬到 0.957，但闭集仍 0.958）；把 `auto` 的选择从单次 val 改为按类数/样本数/交叉验证。

## 6. 边界

- 生产 6 类测试只有 96 个样本；闭集差异不显著，开集差异显著。
- 384 类是合成代理 + 128-d 投影，不是真实 VLM。
- 联合头概率是 LDA 分数上的 softmax，只用于排序；开放集必须用原始 max score + 校准阈值。
- 热更新冻结池化协方差，是近似；协方差漂移时仍需重估。

## 7. 本轮结论：互补性是必要条件，不是充分条件

> **多专家融合的增益来自互补信息，而不是专家数量。互补性是必要条件而非充分条件：低维、样本足够、错误低相关时，特征级联合判别读出显著优于单专家；高维、样本不足或专家高度相关时，特征级 concat 可能反而更差，此时应先白化/降维，并优先考虑分数级融合。能力重合的专家不保证整体更强，且可能损害开放集与校准。**

三组证据放在同一张表里（不同任务不可直接横比，只看同一行内的方向）：

| 场景 | 专家关系 | 单专家 | 融合 | 增益 | 备注 |
|---|---|---:|---:|---:|---|
| 合成 384 类（raw） | **真互补**：vision + tactile + geometry | 0.865 | 0.971（A_full） | **+10.7** | 错误相关 0.014；182/384 类只有一个专家对 |
| 合成 384 类（128-d 投影） | **真互补** | 0.799 | 0.927（A_full） | **+12.8** | 生产原型读出 0.833 → 联合读出 0.927（+9.4，CI [6.0, 13.0]） |
| 生产 6 类（`data/expert_v1`） | 原型 vs 联合头 | 0.990（原型） | 0.958（联合） | −3.1（CI 跨 0） | 开集 AUROC 0.969 → 0.897（−7.2，CI 排除 0） |
| CLEVR raw（1,372-d concat） | **同源视觉** + oracle 几何 | 0.842（`front_shape`） | 0.819 | −0.023 | 24 个任务×子集里只有 3 个正；最大 +0.005，最大 −0.163 |
| CLEVR 128-d 白化 | 同源视觉 + oracle 几何 | 0.842 | 0.832 | −0.010 | 11/24 正；最大 +0.013，最大 −0.120；分数级融合 +0.02~0.04 |

判读：

1. **真互补时，特征级联合建模能把增益兑现**：384 类上 +9.4~+12.8 点，CI 排除 0。
2. **同源/重合时，concat 不保证更大**：CLEVR 上 DINOv2 与 CLIP 错误相关 0.12–0.27，raw concat 只 3/24 正；128-d 白化把协方差估计修好（11/24 正），但最大增益只有 +0.013，说明**白化修的是估计问题，不是互补性**。
3. **融合算子要匹配数据**：低维、真互补 → 特征级 LDA；高维、相关专家 → 先白化/降维，分数级融合更稳；开放集/热更新 → 保留原型头（`auto`/双头）。
4. **“整体能力”要分维度**：闭集精度、开放集拒识、校准、热更新不是同一个量。互补专家在闭集上 +9.4，但联合头在开集上反而更差（0.969 → 0.897），所以生产不能盲目替换。
5. **先测互补性，再谈融合**：看专家间错误相关性、`oracle-any`、`A_full(all) − max A_full(single)`；差距接近 0 时继续加专家没有收益，应修融合器/数据，而不是堆模型。
