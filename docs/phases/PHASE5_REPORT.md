## 3. 结果

### 3.1 识别 top-1

| 查询 | val | test |
|---|---:|---:|
| 融合 + 树 | 0.969 | 0.938 |
| **融合 flat（无树裁剪）** | **0.990** | **0.969** |
| 仅视觉 | **1.000** | **0.969** |
| 仅触觉 | 0.500 | 0.521 |
| 仅几何 | 0.854 | 0.854 |

### 3.2 分层树

- 候选召回 = 识别准确率（val 0.969 / test 0.938）：树一旦把真类别裁掉，识别必错。
- flat 比 tree 高 2–3 个点，说明**贪心 top-1 分支裁剪是唯一损失来源**。
- 二叉树下 `top_n=2` 等价于"全保留"，所以本实验用 `top_n=1`；真正要恢复精度，需要动态 top-N + 下探阈值（9.3.3）。

### 3.3 开放集

| 指标 | 值 |
|---|---:|
| 阈值（val max score 5% 分位） | 0.808 |
| 已见类别误拒率（test） | 0.115 |
| 未见类别拒绝率（test_category） | **0.771** |
| 平均 max score：已见 / 未见 | 0.904 / **0.649** |

开放集方向是对的：未见类别平均分明显更低，77% 被拒。但 11.5% 的误拒率对生产不可接受，阈值需要按模态/场景校准。

### 3.4 冲突检测

| 条件 | 冲突率 |
|---|---:|
| 正常 test | 0.531 |
| 注入跨类别触觉 | **0.969** |

检测器对注入冲突很敏感，但**基线本身就高**——触觉弱，经常与视觉/几何不一致。这说明"冲突标记"不能直接当故障信号，需要先给模态置信度定标。

### 3.5 准入模拟

| 类别 | 决策 | 原因 | 留出集准确率 |
|---|---|---|---:|
| cloth | reject | vision/tactile/geometry 类间距离低 | **1.000** |
| tool | reject | tactile/geometry 类间距离低 | 0.583 |

**这是本阶段最重要的发现**：按当前阈值，`cloth` 被拒，但把它加入原型库后在留出集上 100% 可分。原型距离 ≠ 类别可分性。

### 3.6 阈值校准诊断

现有类别的最近邻距离：

| 范围 | 最小 | 中位 | 0.5×min 阈值 |
|---|---:|---:|---:|
| vision | 0.583 | 0.800 | 0.291 |
| tactile | **0.063** | 0.086 | 0.031 |
| geometry | **0.105** | 0.155 | 0.052 |
| fused | 0.339 | 0.483 | 0.170 |

默认的 `min_inter_distance=0.25` **高于 tactile 和 geometry 的现有最近邻距离**，也就是说它会连现有合法类别一起拒掉。这个门槛是占位值，不是可用规则。

## 4. 三个必须带走的结论

### 4.1 融合没有超过最强单模态

视觉单独 1.000/0.969，融合 0.969/0.938。固定权重把弱触觉拉了进来。真正需要的是**按观测质量动态定标**（9.1.4 的置信度加权），而不是固定 0.5。

### 4.2 层次树是"精度换速度"，且当前裁剪过狠

flat 检索在 6 类规模下本来就便宜；树的价值要在类别数上百时才体现。当前 `top_n=1` 的贪心下降损失 2–3 个点。后续需要：
- 动态 top-N（不是固定 1）；
- 下探阈值；
- ANN 兜底交叉验证。

### 4.3 准入必须多信号 + 人工审核，不能单靠原型距离

`cloth` 的例子说明：
- 原型质心距离低，但样本分布可分（留出 1.0）；
- 单阈值 0.25 会误杀；
- 正确做法是 **聚类方差 + 类间距离 + 留出集可分性 + 人工审核** 联合判断，并且阈值按模态分别校准。

这正是原文 9.6.4 与 9.10 标注的"阈值未定"问题；本阶段把它从文字变成了可复现的数字。

## 5. 冻结的决策

| # | 决策 |
|---|---|
| 1 | 原型按模态独立存储，融合只发生在查询时 |
| 2 | 树由数据驱动构建，上线后冻结；语义审核留到离线流程 |
| 3 | 识别采用四级检索；当前树裁剪为 `top_n=1` 占位 |
| 4 | 开放集阈值从验证集分位数校准，仅作演示 |
| 5 | 准入阈值为**诊断指标**，不是生产规则 |
| 6 | `manifest.json` 记录版本与 sha256，为 L2 OTA 做准备 |
