## 4. 如何解读这些数字

### 视觉 0.958：高，但任务很简单

- 原始几何体 + 强区分的颜色/形状，6 类闭集；留出实例只改变了尺度/颜色变体。
- train 1.000 说明明显过拟合；test 0.958 说明这些类别在实例间仍共享颜色/形状线索。
- **不能**据此声称真实世界视觉泛化。它只证明"裁剪 → CNN → 特征"的管线可用。
- 由于环境没有 torchvision/timm，当前用的是**从零训练的小 CNN**；生产路径应换成真实图像预训练骨干（DINOv2/ResNet），这是 Phase 3 的后续项。

### 几何 0.802：最可靠的一路

- 16 维手工特征（面积、包围盒、实心度、深度统计、质心）在留出实例上 0.802。
- 没有梯度训练，行为可解释；适合作为"感知误差"与"学习误差"的分离基线。
- 这也是 Phase 2 深度/分割真值质量的间接验证。

### 触觉 0.365：接近随机，符合预期

- 6 类随机基线 0.167；0.365 说明合成触觉只携带部分材质信息，远不足以识别类别。
- 数据来源是**材质参数合成**（category）或粗粒度接触投影（episode），不是真实触觉传感器。
- 结论：触觉链路已打通，但**不能**用它做任何真实触觉可分性判断；RD2 真实同步采集是必需项。

---

## 5. 冻结的决策

| # | 决策 |
|---|---|
| 1 | 三个专家的输出维度：视觉 256、触觉 64、几何 16 |
| 2 | 专家权重冻结导出，接口为 `encode(x) -> (B, out_dim)` |
| 3 | 视觉/触觉的分类头只用于评测，不随专家导出 |
| 4 | 几何专家保持手工特征，不训练 |
| 5 | 开放集（`test_category`）不在本阶段评估，留给原型检索 |
| 6 | 当前视觉骨干是冒烟用小 CNN；Phase 4 前可替换为真实预训练骨干，接口不变 |

---

## 6. 已知边界

| 边界 | 说明 |
|---|---|
| 无真实预训练骨干 | torchvision/timm 未安装；小 CNN 从零训练 |
| 数据量小 | 96 训练视图/模态；过拟合明显 |
| 触觉是合成代理 | 不能代表真实传感器 |
| 只做类别级配对 | 没有同实例同刻的视-触同步样本（RD2） |
| 无噪声/域随机化 | 真实传感器分布未覆盖 |
| 闭集评估 | 未见类别未评估 |

## 7. 下一步：Phase 4（投影层与跨模态对齐）

| 工作项 | 说明 |
|---|---|
| 每个模态独立 MLP 投影头 | 视觉 256 / 触觉 64 / 几何 16 → 公共 128 维，L2 归一化 |
| InfoNCE 预训练 | 先用类别级配对（同一 category 的视/触/几何），再考虑实例级 |
| 属性辅助头 | 从投影后向量反预测颜色/材质/尺寸，防止信息坍缩 |
| 冻结锚点协议 | 专家与原型库冻结，只训投影头 |
| 评测 | 跨模态 R@1、属性探针保持率、类间可分性 |

注意：当前数据只有**类别级**配对（同一 category 的样本），没有实例级同步配对；Phase 4 的先验结论只能到"类别原型对齐"，实例级绑定要等 RD2。
