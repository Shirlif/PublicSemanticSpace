## 4. 结论与冻结的决策

| # | 结论 | 决策 |
|---|---|---|
| 1 | Hadamard 槽严格正交；Rademacher 近似正交；Gaussian 有近零分量 | **槽方案 = Hadamard**，D 取 2 的幂 |
| 2 | Hadamard 往返误差 ≈ `noise × sqrt(cycles)` | 误差达 **10%** 前必须 rebind（`REBIND_ERROR_BUDGET=0.10`） |
| 3 | 1% 噪声约 100 轮到 10%；5% 噪声约 10 轮到 16% | rebind 周期按实测噪声标定，不设固定值 |
| 4 | D=128 在 K=5 时容量 1.000；K=20 降到 0.769 | 单向量叠加建议 **≤8**（`RECOMMENDED_MAX_SUPERPOSITION=8`）；20+ 升 D=512 或逐条存储 |
| 5 | Gaussian 槽 K=5 容量仅 0.35–0.40 | **禁止**使用高斯槽 |
| 6 | 容量测试是"全部事实共用一个向量"的压力测试 | 默认存储是分模态、分实体，单实体叠加≈5，处于安全区 |
| 7 | 跨模态相加不可分离（9.2.3） | 实体按模态独立存放；加法只用于单模态打分 |
| 8 | 原 `unbind` 会把近零负分量翻正 | 已改为保号 clamp，单测锁定 |

## 6. Phase 1 建议的起手式

1. 实现关系三元组的**三份独立 bound 分量**存储，并测槽间串扰。
2. 在同一网格上实现 HRR，比较容量与噪声稳定性；若 HRR 在同 D 下容量显著更高，再评估是否替换。
3. 根据关系库设计确定 D：若关系逐条存储，坚持 128；若需要把多条关系压进一个向量，升 256/512。
4. 把 rebind 策略写进绑定模块：误差估计 + 阈值 + 重提取接口。
