## 3. 基线

| 基线 | 定义 | 本环境状态 |
|---|---|---|
| **B1 文本状态** | 每帧检测序列化为文本，跨帧只靠文本位置/类别匹配，无持久实体槽；遮挡后丢失身份 | **代理实现**（无真实 VLM） |
| **B2 行为克隆** | 从演示学习动作策略 | **不运行**：Phase 2 动作是脚本随机，不是目标条件演示 |
| **B3 消融** | 无槽（全局向量）、跨模态相加、随机投影、无场景图 | 运行 |

> B1 不是真实 VLM 对比，只模拟"没有持久实体槽、状态靠文本序列"的结构约束。结论只能用于结构判断，不能外推为"本架构优于某 VLM"。

## 5. 指标定义

- **绑定往返误差**：`||unbind(bind(x,s),s) - x|| / ||x||`
- **ID retention**：同一 GT 实例在观测帧中被同一系统 track ID 覆盖的最大比例
- **ID switches**：同一 GT 实例相邻观测帧之间 track ID 变化的次数
- **关系 F1**：`in / contact / near` 的 micro-F1
- **状态误差**：预测位姿与 GT 的平均欧氏距离
- **属性混淆率**：查询返回其他实体属性的比例（本阶段以识别错误率近似）
- **焦点切换召回**：工作记忆重激活后 raw 特征还原比例
- **任务成功**：目标关系集合被满足

## 6. 边界与承诺

1. 所有数据是 MuJoCo 原始几何体代理；不是真实机器人。
2. 视觉骨干是从零小 CNN，不是真实预训练模型。
3. 触觉是合成代理。
4. E0 在 RD2 真实同步数据到位前**不运行**。
5. B1 是文本状态代理，B2 不运行。
6. 本预注册一旦运行，结果全部写入 `eval/results/phase10_report.md`，包括未达标项。

## 7. RD2 / 实例级对齐状态（2026-11-22）

- 真实 RD2 未采集；Phase 4 的实例级 pair R@1 和 R-Gate **deferred**，不阻塞 Phase 6/7。
- 模拟视角 holdout（train views 0–1 / test views 2–3）：
  - vision-vision R@1 0.380；
  - vision-tactile 0.009；vision-geometry 0.031；tactile-geometry 0.004。
- 结论：当前合成 tactile/geometry 缺少实例级身份信号，不能靠投影修好；不能用它宣称 H6 或 sim2real。
- 仿真器 v2（实例级触觉纹理 + 各轴几何抖动）：QG vision-vision 0.548、vision-tactile 0.120、vision-geometry 0.081；仍低于 0.7。
- 仿真器 v3（8 视角/实例）：QG vision-vision **0.728**、vision-tactile 0.148、vision-geometry 0.108；vision-vision 过 0.7，但跨模态未到 0.3 停止线。
- 结论：瓶颈不只是视角数；各模态实例信号独立随机，缺少共享实例 latent。**停止仿真调参**，下一步 ObjectFolder 2.0（CC-BY-4.0）或最小真实 RD2。
- ObjectFolder 2.0（100）：零样本 R@1 0.010 / R@5 0.120（vision→touch）、0.010 / 0.080（touch→vision）；Ridge 半对象 R@1 0.080 / 0.040，R@5 0.260 / 0.220（chance 0.020）。R@5 有稳定信号，零样本 R@1 不够。
- ObjectFolder 触觉编码器：seen R@1 0.360 / 0.160，held-out 5 折 R@1 **0.220±0.121 / 0.100±0.032**，R@5 **0.580±0.136 / 0.400±0.071**。比零样本/Ridge 明显提升，但未到 0.7。
- ObjectFolder 对称投影：held-out 5 折 vision→touch R@1 0.180±0.060 / R@5 0.620±0.040，touch→vision R@1 **0.140±0.037** / R@5 **0.480±0.108**。对称投影提升 touch→vision，但 vision→touch R@1 略降。
- ObjectFolder 12 触觉点：tactile-only vision→touch R@1 0.220±0.051 / R@5 **0.730±0.117**；symmetric vision→touch R@1 **0.240±0.058** / R@5 0.620。R@5 和稳定性提升，top-1 只到 0.24；触觉覆盖不是唯一瓶颈，下一步增加对象数或换更强编码器。
- 替代路径：ObjectFolder 2.0、或最小真实 RD2 种子集。
- 门禁处理：Phase 4 pair R@1 保持 open/deferred；M2 只能按“仿真类别级 + 模拟视角”收口，不能按真实实例级收口。
